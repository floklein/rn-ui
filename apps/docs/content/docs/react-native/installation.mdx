title: Installation
description: Install UI SDK in your React Native app.

Start with an app using React Native 0.88 and React 19 or newer, like an Expo SDK 58 app.

## Install the Packages

```bash
npm install @ui-sdk/react-native @ui-sdk/core
```

`@ui-sdk/react-native` provides the components. `@ui-sdk/core` provides their behavior and is a peer dependency. Install both so the components and any helpers you use share one copy of the core. Neither package has a dependency of its own, and neither needs a native module, so there's nothing to link or prebuild.

## Import a Component

Import each component from its own entry:

```tsx
import { Switch, SwitchThumb } from "@ui-sdk/react-native/switch"
```

There is no root import from `@ui-sdk/react-native`. Each [component page](./components) lists the parts you can use.

## Add Your Styles

Components are unstyled. Each part takes `style` as a value or as a function of its state, and merges it with its own as an array, never flattened:

```tsx
<Switch style={(state) => [styles.track, state.checked && styles.on]} />
```

The function also receives the part's interaction, `{ pressed, hovered, focused }`, as React Native reports it, for press feedback. `focused` follows keyboard focus on Android only; on iOS, Full Keyboard Access draws its own focus ring. `className` and `children` take the same functions, so styling libraries that read `className`, like NativeWind v5 and Uniwind, work as they are. With NativeWind v4, call `cssInterop` on each part you style.

## Wrap Your App

A modal popup, like a dialog, renders in React Native's `Modal` and needs nothing from your app. A non-modal popup renders above your screens in an `OverlayHost`, so wrap your app in one, near the root:

```tsx title="App.tsx"
import { OverlayHost } from "@ui-sdk/react-native/overlays"

function App() {
  return <OverlayHost>{/* your app */}</OverlayHost>
}
```

The host lets every press through to your screens. A press outside a non-modal popup can still close it, as a click outside one does on the web. Android's back button closes the topmost open popup first. Each `Modal` carries a host of its own, so a popup opened from inside a modal dialog renders inside its `Modal`.

Without an `OverlayHost`, a non-modal popup renders where it is in the tree, and development builds warn you.

## Pass the Safe-Area Insets

`OverlayHost` takes `insets`, the safe-area insets that popups keep clear of: the notch, the status bar and the home indicator. UI SDK never reads them itself, so it adds no dependency. They're zero until you pass them. With `react-native-safe-area-context`, read them inside its provider and pass them on:

```tsx title="App.tsx"
import { OverlayHost } from "@ui-sdk/react-native/overlays"
import {
  SafeAreaProvider,
  useSafeAreaInsets,
} from "react-native-safe-area-context"

function Overlays({ children }: { children: React.ReactNode }) {
  return <OverlayHost insets={useSafeAreaInsets()}>{children}</OverlayHost>
}

function App() {
  return (
    <SafeAreaProvider>
      <Overlays>{/* your app */}</Overlays>
    </SafeAreaProvider>
  )
}
```
