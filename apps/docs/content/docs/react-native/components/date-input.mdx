Use a Date Input for dates people know by heart, like a birthday or a booking date. Each part of the date is its own small `TextInput`, ordered the way the locale writes it.

/>

## Installation

```bash
npm install @ui-sdk/react-native @ui-sdk/core
```

## Composition

Use the following composition to build a `DateInput`:

```text
DateInput
├── DateInputSegment
└── DateInputSegment
```

`DateInput` renders a `View` with one `DateInputSegment` for each part of the date: month, day and year in English, day, month and year in German. Each segment you type in is a `TextInput` with a number pad. The slashes or dots between them are segments too, rendered as `Text`. Without children, `DateInput` renders its segments unstyled; pass a function as children to render and style them, as every example here does.

## Usage

Put the input in a [Field](/docs/react-native/components/field) and give it a label:

```tsx
import {
  DateInput,
  DateInputSegment,
  type DateInputState,
} from "@ui-sdk/react-native/date-input"
import { Field, FieldLabel } from "@ui-sdk/react-native/field"

const segments = ({ segments }: DateInputState) =>
  segments.map((segment) => (
    <DateInputSegment key={segment.key} segment={segment} />
  ))

function Example() {
  return (
    <Field>
      <FieldLabel>Start date</FieldLabel>
      <DateInput defaultValue="2026-11-02" style={{ flexDirection: "row" }}>
        {segments}
      </DateInput>
    </Field>
  )
}

export { Example }
```

The value is an ISO date string like `"2026-11-02"`. It stays `null` until every segment holds something, so your app only sees whole dates.

Type digits and each segment fills, then focus moves to the next one. A month that can't take another digit, like 4, moves on at once. Backspace removes the last digit, then empties the segment, and in an empty segment it moves back to the one before. Leaving a segment keeps what was typed, so a 1 left in the month becomes January. The day is kept within its month. Paste a whole date into any segment, as `2026-11-02` or written the way the locale writes it. A tap around the segments, or on the text between them, starts editing the nearest one.

## Field

Screen readers say the Field's label before each segment's own name, like "Birthday, month", and read its description as each segment's hint. A tap on the label starts editing the first segment.

## Date and Time

Set `granularity` to `"hour"`, `"minute"` or `"second"` to add the time. The value becomes a local date and time like `"2026-11-02T14:30"`. For a time alone, use [Time Input](/docs/react-native/components/time-input).

`min` and `max` take ISO dates. A date outside them is invalid: the state's `invalid` is true, for your styles.

## Unavailable Dates

`unavailable` takes the same matchers as [Calendar](/docs/react-native/components/calendar): ISO dates, `{ from, to }` ranges, weekdays like `{ weekday: [0, 6] }`, or a function. An unavailable date is invalid.

## Locale

The input reads its order, separators and clock from `locale`, or from the device's language when you leave it out. The digits are always 0 to 9, and the calendar is always the Gregorian one. Each segment's name comes from the locale where the device's JavaScript engine has `Intl.DisplayNames`; Hermes doesn't, so segments are named in English there, like "month".

Set `disabled` on the input, or on a `FieldSet` around it, to stop focus and typing.

## Controlled

Pass `value` and update it in `onValueChange`. The callback runs with each whole date, and with `null` once any part of it is erased. A half-typed date already reads `null`, so setting the value to `null` leaves it as typed. Call `clear()` on a [controller](#controller) to empty every segment.

## Forms

A native view takes part in no form, so there's no `name`, `form`, hidden input, submission or reset: read the value from `onValueChange` or the controller.

## Refused Edits

`TextInput` reports an edit after it shows it, so a character a segment can't take, like a letter in the month, appears for a moment and then goes back, with the caret where it was. Digits a segment can't take whole start it again, as on the web: typing 3 in a full month makes it March and moves on.

## Custom Rendering

Pass a function as `children` to render the segments yourself. It gets the input's state, whose `segments` list each segment in order, with the text between them. Render a `DateInputSegment` for each, and give the text between segments children of your own.

<ComponentExample
  name="date-input/segments"
  caption="The segments here are separated by dashes in place of the locale's slashes. The order stays the locale's."
/>

A segment you type in renders a `TextInput`, and the text between segments a `Text`. Give `render` a `TextInput` only when `segment.editable` is true.

## Styling

Style the root as the field's box, with `flexDirection: "row"`, and its segments inside it. A segment's state has its `type`, so you can make the year wider or mute the text between segments, whose type is `"literal"`. An empty segment's `empty` is true and it shows its placeholder, `––` or `––––`; pass `placeholder` to change it. The root's `invalid` is true while the date is out of range or unavailable. Every part receives the fields listed under [Part State](#part-state).

## Accessibility

Each segment is a text field with the spinbutton role, named by the input's name and its unit, like "Birthday, month": the name comes from a Field's label, `aria-labelledby` or `aria-label` on the root, since React Native gives a container's name to no screen reader. A Field's description is each segment's hint. A segment reads its value, range and text, and an empty one reads as "Empty". On Android, TalkBack's adjust actions step a segment by one, as the arrow keys do on the web; VoiceOver can't adjust a text field, so on iOS you type the digits. The text between segments is hidden from screen readers.

### Keyboard

With a hardware keyboard, with iOS Full Keyboard Access or on Android:

| Key             | Does                                                          |
| --------------- | ------------------------------------------------------------- |
| 0 to 9          | Fill the segment, then move to the next one                   |
| Backspace       | Remove the last digit, then empty the segment, then move back |
| A / P           | Choose AM or PM, in a time with a 12-hour clock               |
| Tab / Shift+Tab | Move through the segments, then out of the input              |

There's no stepping with the arrow keys, Page Up, Page Down, Home or End, and no Delete, since `TextInput` doesn't report those keys. Android reports Backspace only from the on-screen keyboard, so with a hardware keyboard Backspace in an empty segment stays there.
