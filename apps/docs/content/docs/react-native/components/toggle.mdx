Use a toggle for a button that stays on until you press it again, like starring a document or turning on Bold. Put several in a toggle group to share one value, as a text editor's formatting buttons or a view switcher do.

/>

## Installation

```bash
npm install @ui-sdk/react-native @ui-sdk/core
```

## Composition

Use the following composition to build a `Toggle`:

```text
Toggle
└── ToggleIcon
```

And a `ToggleGroup`:

```text
ToggleGroup
├── Toggle
│   └── ToggleIcon
└── Toggle
    └── ToggleIcon
```

`Toggle` renders a `Pressable` with the toggle button role and its pressed state. `ToggleIcon` is optional: a `View` that holds an icon and hides it from screen readers. `ToggleGroup` renders a `View`. In a group, give each toggle a `value`; the group's value lists the pressed ones.

## Usage

Import the parts and put them together:

```tsx
import { Toggle, ToggleIcon } from "@ui-sdk/react-native/toggle"
import { Text } from "react-native"

function Example() {
  return (
    <Toggle aria-label="Star">
      {(state) => (
        <ToggleIcon>
          <Text>{state.pressed ? "★" : "☆"}</Text>
        </ToggleIcon>
      )}
    </Toggle>
  )
}

export { Example }
```

Keep the name the same in both states: VoiceOver and TalkBack announce whether the toggle is pressed. A toggle with only an icon needs an `aria-label`, as above; otherwise the `Text` inside names it. Set `defaultPressed` to start pressed.

## Group

Put toggles in a `ToggleGroup`, from the same `@ui-sdk/react-native/toggle` entry, to share a value. Give the group an `aria-label` and each toggle a `value`. Set `multiple` to let several toggles stay pressed.

<ComponentExample
  name="toggle/group"
  caption="Tap Bold and Italic to keep both pressed. With VoiceOver or TalkBack, swipe from one toggle to the next."
/>

The group owns which toggles are pressed, so a toggle's own `pressed` and `defaultPressed` don't apply inside it. Its value is always an array, in the order the toggles render, whatever order they were pressed in. A toggle that mounts later between two others takes its place.

## Single Selection

Without `multiple`, pressing a toggle unpresses the others. Pressing the pressed toggle again clears the selection, unless you set `deselectable` to `false`, as this alignment group does. `deselectable` doesn't choose an initial value for you, so pair it with `defaultValue`.

<ComponentExample
  name="toggle/group-single"
  caption="Tap Align center to replace Align start, then tap Align center again. One alignment always stays pressed."
/>

`mirror` on Align start and Align end flips their icons when the app runs right to left, with `I18nManager`. React Native has one direction for the whole app, so there's no direction for part of the screen.

## Disabled

Set `disabled` on a toggle or a group to prevent presses. A disabled toggle can still start pressed, and screen readers announce it as dimmed or disabled.

```tsx
<ToggleGroup multiple aria-label="Text formatting">
  <Toggle value="bold">
    <Text>Bold</Text>
  </Toggle>
  <Toggle value="underline" disabled>
    <Text>Underline</Text>
  </Toggle>
</ToggleGroup>
```

On Android the disabled state disables the view, so Tab skips a disabled toggle, in a group too. `focusableWhenDisabled` leaves the `Pressable` of a toggle on its own enabled while it's disabled; presses still do nothing, and on Android the disabled state disables the view anyway.

## Controlled

Pass `pressed` and update it in `onPressedChange`. Call `details.cancel()` in the callback to keep the current state. A [controller](#toggle-controller) from `createToggleController()` presses the toggle from anywhere. Create one controller per mounted toggle.

```tsx
import { useState } from "react"
import { Pressable, Text } from "react-native"
import { createToggleController, Toggle } from "@ui-sdk/react-native/toggle"

function StarButton() {
  const [starred, setStarred] = useState(false)
  const [star] = useState(createToggleController)

  return (
    <>
      <Toggle
        aria-label="Star"
        pressed={starred}
        onPressedChange={setStarred}
        controller={star}
      >
        <Text>{starred ? "★" : "☆"}</Text>
      </Toggle>
      <Pressable accessibilityRole="button" onPress={() => star.toggle()}>
        <Text>Toggle Star</Text>
      </Pressable>
    </>
  )
}

export { StarButton }
```

The callback receives the new state and `details`, whose `reason` is `"press"` or `"imperative"`, and whose `source` is `"touch"`, or `"virtual"` while a screen reader runs. The controller's `focus()` moves VoiceOver's or TalkBack's focus to the toggle.

## Controlled Group

Pass `value` and update it in `onValueChange` to own the group's value. A toggle's own `onPressedChange` runs before the group's, and calling `details.cancel()` in either cancels the change. A [controller](#togglegroup-controller) from `createToggleGroupController()` changes the value from anywhere: `setValue([])` clears it, and `focus(value)` moves the screen reader's focus to a toggle.

```tsx
import { useState } from "react"
import { Pressable, Text } from "react-native"
import {
  createToggleGroupController,
  Toggle,
  ToggleGroup,
} from "@ui-sdk/react-native/toggle"

function Formatting() {
  const [formats, setFormats] = useState(["bold"])
  const [editor] = useState(createToggleGroupController)

  return (
    <>
      <ToggleGroup
        multiple
        aria-label="Text formatting"
        value={formats}
        onValueChange={setFormats}
        controller={editor}
      >
        <Toggle value="bold">
          <Text>Bold</Text>
        </Toggle>
        <Toggle value="italic">
          <Text>Italic</Text>
        </Toggle>
      </ToggleGroup>
      <Pressable accessibilityRole="button" onPress={() => editor.setValue([])}>
        <Text>Clear Formatting</Text>
      </Pressable>
    </>
  )
}

export { Formatting }
```

### Events

Callbacks get the new state or value first, then the details. `onValueChange` never runs on mount.

| Prop              | On            | Receives                                                                                                                     |
| ----------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `onPressedChange` | `Toggle`      | `(pressed, details)`: the new state, and the [reason](#reasons). In a group, it runs first and can cancel the group's change |
| `onValueChange`   | `ToggleGroup` | `(value, details)`: the pressed toggles' values, and the [reason](#reasons)                                                  |

## Accessibility

A toggle follows the toggle button in the [WAI-ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/), translated to React Native's accessibility props: the `togglebutton` role with its checked and disabled state, so VoiceOver and TalkBack announce whether it's pressed, and a double-tap presses it. In a group, each toggle is its own accessible element, reached by swiping. The group is a `View` with no role, since React Native has no group role.

### Keyboard

With a hardware keyboard, with iOS Full Keyboard Access or on Android:

| Key        | Does                                                         |
| ---------- | ------------------------------------------------------------ |
| Tab        | Moves to the next control, and Shift-Tab to the previous one |
| Arrow keys | Move between controls, on Android only                       |
| Space      | Presses or unpresses it                                      |
| Enter      | Presses or unpresses it, on Android only                     |

Every toggle in a group is its own stop: React Native delivers no arrow keys to views, so the group's single tab stop and arrow keys aren't built.
