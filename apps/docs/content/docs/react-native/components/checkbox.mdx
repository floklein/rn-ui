Use a checkbox for a choice someone can check or uncheck. Use a group when several choices belong to one value.

## Installation

```bash
npm install @ui-sdk/react-native @ui-sdk/core
```

## Composition

Use the following composition to build a `Checkbox`:

```text
CheckboxGroup
├── Checkbox
│   └── CheckboxIndicator
└── Checkbox
    └── CheckboxIndicator
```

`Checkbox` renders a `Pressable`, and `CheckboxIndicator` and `CheckboxGroup` render a `View`. A checkbox works on its own too, without a group.

## Usage

Import the parts and put them together. A native view has no `<label>` to wrap it in, so put the label's text inside the checkbox: it names the checkbox, and a tap anywhere on the row checks it.

```tsx
import { Checkbox, CheckboxIndicator } from "@ui-sdk/react-native/checkbox"
import { Text, View } from "react-native"

function Example() {
  return (
    <Checkbox>
      <View>
        <CheckboxIndicator>
          <Text>✓</Text>
        </CheckboxIndicator>
      </View>
      <Text>Accept terms and conditions</Text>
    </Checkbox>
  )
}

export { Example }
```

The indicator is mounted while the checkbox is checked or indeterminate.

`readOnly` keeps the checkbox focusable while preventing the user from changing it. Use it for a setting managed somewhere else. It isn't announced, so say why in the label or nearby text.

## Indeterminate

An indeterminate checkbox represents a partly checked set. Screen readers announce it as mixed. A press checks it; only your code puts it back into the mixed state.

Start with `defaultChecked="indeterminate"`, or pass `"indeterminate"` as the controlled value. The indicator's state tells it which mark to show. A [parent checkbox](#parent-checkbox) derives this state from a group for you.

```tsx
<Checkbox aria-label="Select all" defaultChecked="indeterminate">
  <CheckboxIndicator>
    {(state) => <Text>{state.indeterminate ? "–" : "✓"}</Text>}
  </CheckboxIndicator>
</Checkbox>
```

## Forms

A native view takes part in no form, so the checkbox and the group have no `name` or `form` prop and render no hidden input. Read the value from `onCheckedChange`, `onValueChange` or a controller. `required` stays in the state for your styles and labels.

## Group

`CheckboxGroup` keeps one list of checked values. Each checkbox supplies its `value`, and the group returns the checked values in the order the checkboxes mounted. Name the group with `aria-label`.

## Animation

The indicator leaves through `onExit`. When the checkbox unchecks, the indicator calls `onExit` with a `done` function and stays mounted until you call it, or until two seconds pass. Meanwhile it takes no touches and screen readers skip it. Without `onExit`, it unmounts at once. Checking the checkbox again before `done` cancels the exit, and a late `done` does nothing.

Start your exit animation in `onExit` and pass `done` as its completion:

```tsx
const opacity = useRef(new Animated.Value(1)).current

<CheckboxIndicator
  onExit={(done) =>
    Animated.timing(opacity, {
      toValue: 0,
      duration: 200,
      useNativeDriver: true,
    }).start(done)
  }
  render={<Animated.View style={{ opacity }} />}
/>
```

The indicator's state also has `startingStyle`, true for its first frame after it appears, and `endingStyle`, true while it leaves, so a style can start from one and end at the other. `keepMounted` keeps the indicator mounted while unchecked: unchecking still calls `onExit`, and the indicator stays once `done` runs.

### Events

Callbacks get the new state or value first, then the details.

| Prop              | On                  | Receives                                                                               |
| ----------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `onCheckedChange` | `Checkbox`          | `(checked, details)`: `true`, `false` or `"indeterminate"`, and the [reason](#reasons) |
| `onValueChange`   | `CheckboxGroup`     | `(value, details)`: the checked values, and the [reason](#reasons)                     |
| `onExit`          | `CheckboxIndicator` | `(done)`: call it when the exit animation ends                                         |

## Accessibility

The checkbox follows the [WAI-ARIA checkbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/), translated to React Native's accessibility props, and a group's parent checkbox follows its [mixed checkbox example](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/examples/checkbox-mixed/). `Checkbox` has the `checkbox` role and its checked and disabled state, so VoiceOver and TalkBack announce it as a checkbox that's checked, unchecked or mixed, and a double-tap toggles it.

### Keyboard

With a hardware keyboard, with iOS Full Keyboard Access or on Android:

| Key        | Does                                                         |
| ---------- | ------------------------------------------------------------ |
| Tab        | Moves to the next control, and Shift-Tab to the previous one |
| Arrow keys | Move between controls, on Android only                       |
| Space      | Checks or unchecks it, or checks a mixed one                 |
| Enter      | Checks or unchecks it, on Android only                       |
